# いわゆる、趣味のお部屋というところです
## Portable NAS System(P-NAS)
逸般人の方は家にゴロゴロと転がっているだろう、SDカードやUSBメモリを簡易的な持ち運び可能なNAS(Network Attached Storage)にしてやろうとかいうアプリです。<br>
このディレクトリ配下にある、3つのファイルをすべてNAS化したい媒体のroot下にコピーしてください。<br>
「Start-SDNAS.cmd」を実行すると、3つのディレクトリが作成されます。<br>
「Data」・「Config」・「Logs」の3つです。「Data」ディレクトリにはNASに入れたいデータを格納してください。「Config」ディレクトリには設定ファイルが書き込まれます。「Logs」ディレクトリにはログが書き込まれます。<br>
iOS系からSMBで接続するときは、純正ファイルアプリではなく、「Documents」アプリを推奨します。Mac OSでも接続できるはずですが、開発者が大貧民のため、接続の確認ができていません。

### 概要

P-NASは、SDカードやUSBメモリをWindows PCに接続している間だけ、同一ネットワーク上の端末から利用できる簡易NASとして公開するためのツールです。

媒体を取り外した場合は、保存されているデータへアクセスできなくなります。設定やログを含む実行環境を媒体内にまとめて持ち運べるため、対応するWindows PCがあれば、その場で簡易ファイル共有環境を立ち上げられます。

### 主な機能

- SDカードやUSBメモリ内の「Data」ディレクトリをSMB共有
- Windows、iPhone、iPadなど、SMBに対応した端末から読み書き可能
- 接続に利用できるIPアドレスを起動時に表示
- Tailscaleが利用可能な場合は、Tailscale側のIPアドレスも表示
- 実行時の設定を「Config」ディレクトリに保存
- 実行ログを「Logs」ディレクトリに保存
- 媒体ごとに共有名とユーザーを分離
- 終了時に共有設定や一時的なネットワーク設定を可能な範囲で復元

### 動作環境

- Windows 10またはWindows 11
- 管理者権限を使用できるユーザー
- SMB通信が可能なローカルネットワーク
- SDカード、USBメモリ、外付けSSDなど、Windowsからドライブとして認識される媒体

> [!IMPORTANT]
> 起動処理ではWindowsのファイル共有設定やファイアウォール設定を変更する場合があります。必ず内容を確認できる自分のPCで実行してください。

### 導入方法

1. 「Portable NAS System(P-NAS)」ディレクトリ内にある3つのファイルを、NAS化したいSDカードまたはUSBメモリのルート直下へコピーします。
2. 媒体のルート直下にある「Start-SDNAS.cmd」を実行します。
3. ユーザーアカウント制御が表示された場合は、内容を確認して管理者権限での実行を許可します。
4. 初回起動時に「Data」「Config」「Logs」の3つのディレクトリが自動作成されます。
5. 共有したいファイルを「Data」ディレクトリへ保存します。
6. 画面に表示された共有名、ユーザー名、IPアドレスを使い、別の端末から接続します。

### ディレクトリ構成

```text
媒体のルート/
├─ Start-SDNAS.cmd
├─ その他のP-NAS構成ファイル
├─ Data/
├─ Config/
└─ Logs/
```

- **Data**: NASとして共有するファイルの保存先です。
- **Config**: P-NASが使用する設定ファイルの保存先です。
- **Logs**: 起動、接続、終了処理などのログの保存先です。

### 接続方法

起動後の画面に、共有名、ユーザー名、接続先候補が表示されます。表示された値をそのまま利用してください。

#### Windows

エクスプローラーのアドレスバーに、次のいずれかを入力します。

```text
\\コンピューター名\共有名
```

```text
\\IPアドレス\共有名
```

認証画面が表示された場合は、P-NASの起動画面に表示されたユーザー名とパスワードを入力してください。

#### iPhone・iPad

SMBクライアントから、起動画面に表示されたIPアドレスへ接続します。

```text
smb://IPアドレス
```

純正の「ファイル」アプリでは接続や書き込みが安定しない場合があるため、本プロジェクトでは「Documents」アプリの利用を推奨します。

#### Tailscale経由

PCと接続端末の両方が同じTailscaleネットワークへ参加しており、起動画面にTailscaleのIPアドレスが表示された場合は、そのIPアドレスを接続先として利用できます。

> [!NOTE]
> Tailscale経由の接続可否は、Windowsファイアウォール、SMB設定、Tailscale側のアクセス制御によって変わります。

#### macOS

Finderの「移動」から「サーバへ接続」を選択し、次の形式で入力します。

```text
smb://IPアドレス/共有名
```

macOSでの動作は未確認です。利用できた場合は、Issueなどで動作環境を報告してもらえると助かります。

### 終了方法

P-NASの起動画面を閉じるか、用意されている終了操作を実行してから、SDカードやUSBメモリを取り外してください。

> [!WARNING]
> ファイルの書き込み中に媒体を抜くと、保存中のファイルやファイルシステムが破損する可能性があります。P-NASを終了した後、Windowsの「ハードウェアを安全に取り外してメディアを取り出す」を実行してください。

### トラブルシューティング

#### 別の端末から接続できない

- PCと接続端末が同じローカルネットワークに接続されているか確認してください。
- 起動画面に複数のIPアドレスが表示される場合は、Wi-Fiまたは有線LANに割り当てられたIPアドレスを優先してください。
- VirtualBox、Hyper-V、VPNなどの仮想アダプターに割り当てられたIPアドレスでは、接続できない場合があります。
- Windows側でネットワーク探索とファイル共有が許可されているか確認してください。
- 共有名では接続できない場合、IPアドレスを直接指定してください。

#### iPhone・iPadで読み取り専用になる

- 接続時にゲストではなく、P-NASが表示したユーザー情報でログインしてください。
- 純正「ファイル」アプリではなく「Documents」アプリを試してください。
- 媒体本体やSDカードアダプターの書き込み禁止スイッチを確認してください。
- Windows上で媒体へ直接ファイルを書き込めるか確認してください。

#### 認証画面が繰り返し表示される

WindowsやSMBクライアントに古い認証情報が残っている可能性があります。保存済みの資格情報を削除し、起動画面に表示された最新のユーザー名とパスワードで再接続してください。

#### ログを確認したい

「Logs」ディレクトリ内の最新ログを確認してください。Issueを作成する際は、パスワード、ユーザー名、IPアドレスなどの個人情報を削除してから添付してください。

### セキュリティ上の注意

- 信頼できる家庭内LANや自分で管理しているネットワークで使用してください。
- 公衆Wi-FiではSMB共有を有効にしないでください。
- 重要情報、機密情報、唯一の原本となるファイルは保存しないでください。
- パスワードや設定ファイルを第三者へ共有しないでください。
- 利用後はP-NASを終了し、不要な共有が残っていないことを確認してください。
- 「Data」ディレクトリ内のデータは、別の媒体にもバックアップしてください。

### 既知の制限

- Windows以外でP-NAS自体を起動することは想定していません。
- macOSからの接続は未確認です。
- ネットワークやSMBクライアントの設定によっては接続できない場合があります。
- FAT32形式の媒体では、1ファイルあたり4GBを超えるファイルを保存できません。
- PCがスリープ、シャットダウン、ネットワーク切断の状態になると接続できません。
- SDカードやUSBメモリの速度および耐久性により、転送性能は大きく変わります。

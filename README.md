# いわゆる、趣味のお部屋というところです
## Portable NAS System(P-NAS)
逸般人の方は家にゴロゴロと転がっているだろう、SDカードやUSBメモリを簡易的な持ち運び可能なNAS(Network Attached Storage)にしてやろうとかいうアプリです。<br>
このディレクトリ配下にある、3つのファイルをすべてNAS化したい媒体のroot下にコピーしてください。<br>
「Start-SDNAS.cmd」を実行すると、3つのディレクトリが作成されます。<br>
「Data」・「Config」・「Logs」の3つです。「Data」ディレクトリにはNASに入れたいデータを格納してください。「Config」ディレクトリには設定ファイルが書き込まれます。「Logs」ディレクトリにはログが書き込まれます。<br>
iOS系からSMBで接続するときは、純正ファイルアプリではなく、「Documents」アプリを推奨します。Mac OSでも接続できるはずですが、開発者が大貧民のため、接続の確認ができていません。
